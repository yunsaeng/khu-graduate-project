# 리뷰 체크리스트

## 기획·설계
- [ ] PRD 성공 기준이 측정값으로 확인되는가
- [ ] 비범위 밖의 기능이 추가되지 않았는가
- [ ] API 명세와 구현이 일치하는가
- [ ] 기술 변경마다 ADR이 있는가

## 구현
- [ ] 작업별 완료 기준 체크 완료
- [ ] 테스트 통과 (명령어와 결과 기록)
- [ ] 비밀값이 커밋에 없다 (.env, 키, 토큰, git log 포함)
- [ ] 보안 시연 코드가 로컬 한정이다

## 보안 시나리오
- [ ] S-xx 별로 취약 버전 성공 / 안전 버전 차단 확인

## 기록
- [ ] measurements의 수치마다 방법·환경·커밋이 있다
